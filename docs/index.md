# TeamDocs — edición colaborativa

Plataforma web donde equipos crean, comparten y co-editan documentos en tiempo real.

- **App:** Next.js + Tiptap + Yjs (sala por documento) + Better Auth + Drizzle.
- **Tiempo real:** Hocuspocus WS persistente (Render/Railway), NeonDB persistente (PG17).
- **Seguridad:** permisos en backend + WS, invitaciones con expiración, auditoría.

Repo: https://github.com/Kratos561/teamdocs-platform
